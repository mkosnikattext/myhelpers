List → Regex

Paste any list of strings separated by new lines, commas, semicolons, spaces, or tabs. The generated regex matches only the values from your list.

0 values 0 characters
The output uses a standard regex alternation pattern. With Exact whole-value match enabled, it will look like ^(value1|value2|value3)$, meaning the entire field must exactly match one of your values. Without it, the pattern is (value1|value2|value3) for substring matching. Regex-special characters inside values are escaped automatically.
